# This Week at Omo — website feed

Powers the **This Week at Omo** section on [omomercado.com](https://www.omomercado.com).

- `week.json` — this week's lineup (the only thing that changes each week, plus photos)
- `photos/` — that week's photos, named `YYYY-MM-DD-event-omo-mercado.jpg`
- `widget.js` — draws the section and adds Event info for Google / AI search; never needs editing
- `snippet.html` — the one-time Squarespace Code Block
- Preview: https://omomercado.github.io/this-week/

Updated weekly by Claude after the IG stories are approved.
